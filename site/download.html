Verify what you downloaded

Every release publishes a SHA256SUMS file alongside the artifacts. Checking it takes one command. 

sha256sum --check --ignore-missing SHA256SUMS
# keyvibes_0.1.1_amd64.deb: OK

The sums are published in the same GitHub release as the binaries; they are not independently signed. Nothing here downloads or executes on your behalf.

Requirements

Kernel

Linux 5.x or newer

The evdev interface and /dev/input nodes, which every distribution ships.

Audio

PipeWire

Your session's PipeWire socket. PulseAudio setups that run through PipeWire's compatibility layer work too.

Access

Read access to input devices

Membership of the input group, or the shipped udev rule. KeyVibes never asks for root.

Desktop app

GTK 4 + libadwaita

Only for keyvibes-ui. The engine runs fine on a headless machine.

Install from a terminal

Debian / Ubuntu

sudo apt install ./keyvibes_0.1.1_amd64.deb

Arch Linux

makepkg -si # in the directory holding the PKGBUILD

Portable / installer

Download both the archive and install.sh into the same directory. The installer is offline: it verifies the archive against a baked-in checksum, then unpacks and installs it.

chmod +x install.sh
./install.sh
