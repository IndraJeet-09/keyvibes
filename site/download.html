Verify what you downloaded

Every release publishes a SHA256SUMS file alongside the artifacts. Checking it takes one command. 

sha256sum --check --ignore-missing SHA256SUMS
# keyvibes_0.1.0_amd64.deb: OK

Compare the fingerprint against the value published in the release notes. Nothing here downloads or executes on your behalf.

Requirements

Kernel

Linux 5.x or newer

The evdev interface and /dev/input nodes, which every distribution ships.

Audio

PipeWire

Your session's PipeWire socket. PulseAudio setups that run through PipeWire's compatibility layer work too.

Access

Read access to input devices

Membership of the input group, or the shipped udev rule. KeyVibes never asks for root.

Desktop app

GTK 4 + libadwaita

Only for keyvibes-ui. The engine runs fine on a headless machine.

Install from a terminal

Debian / Ubuntu

sudo apt install ./keyvibes_0.1.0_amd64.deb

Fedora / openSUSE

sudo rpm -i keyvibes-0.1.0-1.x86_64.rpm

Arch Linux

makepkg -si # in the directory holding the PKGBUILD

Portable / installer

tar -xzf keyvibes-0.1.0-x86_64-linux.tar.gz
./keyvibes-0.1.0-x86_64-linux/install.sh
